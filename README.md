## 🕹 Управление:

- **W / A / S / D** — движение
- **Мышь (X & Y)** — обзор
- **Пробел (Space)** — прыжок
- **C** — подкат (slide)
- **Левый Shift** — бег
- **Левая кнопка мыши** — выстрел
- **R** — перезарядка
- **E** — взаимодействие

## 🧩 Особенности:

- Реализована **паркур-система** для добавления динамики в геймплей: подкат, ускорение, прыжки, с плавным контролем.
- **Система попаданий по врагам** реализована через физическое попадание **по мешу и имени кости**.
- Урон зависит от зоны попадания:
    - **Голова** — повышенный урон
    - **Тело и конечности** — стандартный урон
- Каждое попадание рассчитывается точно, исключая абстрактные коллизии.
